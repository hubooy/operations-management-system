# 市场榜单与本店商品的人工复核候选

`backend/business_analysis/market_own_mapping.py` 是纯只读衍生器。输入必须是已经由各自 owning reader 完整读取、并与独立封存的 `PageReconciler.result()` 一致的市场 `market_daily_top` 页和京东选定店铺当前 `product_master` 页。调用方负责在权限与任务检查点中证明这些封存记录可信，不能让模型自报摘要充当独立证明。

该衍生器仅支持京东。市场页明确没有店铺归属；它与选定店铺主数据须平台相同，主数据须是当前选定店铺的最新已完成快照，且所有商品行属于该封存批次。市场窗口日期必须与调用方明确指定范围一致，所有市场行日期均在范围内。只用 SKU 对 SKU、SPU 对 SPU 的原始精确主键产生 `candidate`；商品名、品牌、价格、类目和商家编码均不用于猜测匹配。

`candidate` 始终有 `manualConfirmationRequired=true`、`historicalOwnershipVerified=false`、`marketSalesAttributedToShop=false`。它仅提示“当前店铺主数据出现相同精确商品主键”，不表示该市场商品由本店经营，不把 TOP 样本销量、访客或成交区间记入本店业绩，也不证明历史期间归属。一个 SKU 在当前主数据重复出现、缺少主数据或精确主键、市场行无名次时返回 `unresolved`。SPU 下的多个 SKU 变体只返回 SPU 身份，不随机选择其中一个 SKU。用户明确传入的商品主键不在完整 TOP 样本时返回 `not_ranked_in_sample`；若市场日期存在覆盖缺口，则返回 `market_coverage_incomplete`，不能把缺数据解释为未入榜。原始覆盖对象和当前主数据快照日期随结果保留。

整份来源先核对页摘要、游标顺序、行数和控制总计，再发布候选。每份来源最多 1,000 页、20,000 行、32 MiB，单页最多 128 KiB；显式待查主键最多 1,000 个。超限报错，不截断。结果按日期、榜单维度、精确主键、来源行 ID 稳定排序；摘要覆盖完整结果；读取每页最多 100 行且不超过 38,000 UTF-8 字节，调用者不能变异已保存结果。

目前仅提供纯衍生器和单元验证，没有注册 Agent 工具、持久化候选、业务写入或报告列。未来接入须把两侧封存 `sourceRef`、完整页核对记录、当前主数据快照、人工确认状态及页面诊断一起绑定任务版本；缺少其中一项时不得输出“自家商品在市场排名”的肯定结论。
