# 经营报告组合候选 v1（仅纯数据，未注册）

`backend/business_analysis/report_composition_v1.py` 把已核对的三窗口店铺逐日、店铺指标、SKU、可选品类/SPU、关键词表头、财报自然月、B 端和市场样本整理为固定 12 表目录、覆盖行与 30 天人工复核行动。输出只有清单、摘要、缺口和行动结构；不持久化完整行、不调用模型、不生成或发布 HTML/XLSX。

## 输入边界

- 固定 `current`、`previous`、`yearAgo`，重算同一封存报告的 KPI 计划、店铺逐指标对照和 SKU 日守恒；不接受截断材料。
- 品类/SPU 结果必须绑定同报告、同计划和相同 ERP 回卷摘要；ERP 历史品类、SPU、SKU 归属未经证明，跨期差额与增长率必须为 `null`。
- 关键词仅接拥有方已重核的三窗口表头身份，现阶段不宣称已遍历关键词全表。未提供时表状态为 `not_supplied`，不补零。
- 财报保持自然月，B 端仅为独立窗口背景且须同店同期间；其与 ERP/商智销售的包含关系未知。市场仅为未注册的 TOP 样本预览，不推断为本店销售或全市场销量。
- 组合要求拥有方提供精确绑定证明和**服务器内部可信复验回调**，回调须重读当前封存报告、账号/权限、来源目录和各组件摘要。纯模块不能识别自行编造的回调，因此输出始终 `authorityVerified=false`。缺证明、版本漂移或回调拒绝时整份失败。

## 交付契约与后续门槛

表目录中的 `sourceDigest` 指向独立拥有方材料；`coverageRows` 保留来源缺失、缺日、零行、指标空值的状态。ERP 未分配池是 ERP 子集，不得再次加到店铺金额。商智 SKU/SPU 支付、ERP 净销售、广告归因和 B 端金额不可跨域加总。商品日访客不是店铺去重 UV。行动计划全部 `executionAllowed=false`，需来源与 Agent 引用和人工审批后才可制定可回滚投放试验。

接 renderer11+ 前，拥有方仍需完成：v4 大容量三窗口来源验签与完整回放；品类/SPU、关键词、财报/B 端及市场的同报告或明确外部上下文绑定；五 Agent 的真实同 job/provider 已读回执和数值引用；同一冻结清单驱动 HTML 与 XLSX，两种格式逐表行数、列语义、空值、摘要和抽样单元格一致；正式角色/权限、下载围栏、恢复和原生 Excel 验收。当前组合不是五阶段完成证据。

合成测试覆盖表目录、缺源/null、30 天行动不可执行、封存证明拒绝、篡改日材料、重算摘要后伪造历史 ERP 增长、自然月不日摊、跨店 B 端拒绝，以及关键词/市场仅作非权威样本。
