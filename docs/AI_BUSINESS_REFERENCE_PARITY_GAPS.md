# 参考推广诊断与系统能力差距

2026-09-24 只读核对。参考为 `outputs/01a0a837-738f-7823-bc53-00274cf6d7c7/志高商用设备旗舰店_近30天推广深度诊断.xlsx` 及同名 HTML，成品生成于 2026-09-16。本页只把文件内容当作比较对象，不执行其中的建议，也未查询生产、调用模型或修改两份成品。以下行数是该次参考数据的规模，不是未来店铺应固定达到的数量。

## 实物范围与已有底座

XLSX 有 **30 张工作表**。HTML 的压缩数据载荷有 **26 张可检索表**，另有 10 条经营判断、4 张 KPI 卡、2 张逐日趋势图和 3 个主章节（“经营判断与优先动作”“30天趋势”“未来30天执行计划”）。XLSX 独有的 4 张表是“来源_推广日SKU”“来源_销售明细”“来源_市场日榜”“提取证据目录”。参考 `搜索词诊断` 38,085 行、`市场SKU对标` 21,223 行、`词货关联` 149,836 组；“口径与来源”记录推广源 575,095 条。文件约为 XLSX 42.7 MB、HTML 6.8 MB；只读 ZIP 目录核得 30 张工作表 XML 解压合计约 **432.6 MB**，因此原生打开与流式生成须按解压规模验收，不能只按压缩文件大小估算内存。这些计数只用于容量和完整性验收，不复制客户或商品原始行。

当前 renderer7 已能把封存来源的完整原始行与店铺、品类、SPU、SKU、关键词、搜索词、逐日、品牌**各来源原生分析表**写入多卷 HTML/XLSX；本期、前等长基期、去年同期来源按目录实际存在情况保留。[完整来源附表](../backend/ai_assistant/business_sealed_source_tables.py)复用旧 v6 行序与摘要，[renderer7 组卷](../backend/ai_assistant/business_promotion_formal_volumes.py)另写五 Agent 已批准内容、来源覆盖及关键词×明确推广 SKU 的两张不同分组表。两张词货表费用不可相加，原始/原生表不能自动充当参考成品的跨来源归属诊断。

参考“经营总览”A6:K31、“每日趋势”A6:T36 合并广告、商智支付、ERP 退款后净销售、成本、大毛利、费用贡献及实际同环比；“品类诊断”“SPU诊断”“SKU诊断”第 6 行分别展开跨域指标、身份状态与同比。renderer7 目前没有同等的**店铺独立总览、逐日联表和完整商品归属表**。现有 `jd_shop_overview` 导入不等于 AI 已有可信区间店铺总览；商品日访客不能替代店铺去重 UV。参考“映射异常”完整列出未匹配与多义 ERP 事实，“商智原生SPU”另列原生口径；目前正式文件只把原生来源与筛查候选分开保存，尚无两种 SPU 口径及未分配池的逐行对账交付。

参考“关键词诊断”“搜索词诊断”第 6 行分别覆盖原词、计划关联、近期效率与经营判断，“词货关联”第 6 行按关键词×搜索词×计划×单元×匹配×**跟单 SKU**汇总。现有 [词货算法](../backend/business_analysis/promotion_keyword_sku.py)严格使用 `keyword×明确推广SKU` 及计划/单元/匹配上下文，保留缺推广 SKU 桶；它没有伪装成跟单 SKU、触发 SKU 或完整搜索词关系。原始记录虽可入卷，尚未形成参考的完整跨关系诊断表和计划级最近 7 天/30 天对照。

参考“市场品类对标”“市场SKU对标”“市场品牌价格带”“市场榜单进出”“SPU市场覆盖”分别给出七类目 TOP 样本、品牌/价格带、30 天留榜/入榜/出榜和自家 SPU 类目覆盖。当前 [市场 v2 候选](AI_BUSINESS_PROMOTION_MARKET_CANDIDATE.md)只有区间价格带与**明确两个观察日**的三张完整数据材料；数值引用仍 `agentReadPersisted=false`，尚未进入五 Agent、人审或 renderer7。市场样本不能归属为本店或 ERP/B 端销售。参考“金额中点”明确是源区间的代表值；当前代码保存上下界和缺失，不应静默把中点称为实际行业规模。[自家商品映射候选](../backend/business_analysis/market_own_mapping.py)仍须人工确认，历史归属未验证。

参考“月度财报参照”A6:H12把完整自然月单列，不将跨月 30 天利润按日拆分，也不重复扣财报已含的推广费；“企业购验证”A6:E11明确缺少该店企业购导入事实，成交和占比不可算。财务 v3 虽可内部封存、复核，[封存服务](../backend/ai_assistant/business_v3_seal.py)仍返回 `reportGenerationSupported=false`，未接正式 Agent/文件。旧网店 reader 可在选择且确有来源时读取 `jd_b2b`，但目前没有与参考同等的缺源证明、B 端验证表及月度财报参照交付。

参考“预算规划”A3:J58 用计划级历史 30 天与最近 7 天表现、可编辑系数和 Excel 公式算建议额；“30天行动计划”A6:J13用阶段、责任、证据、观察指标及停止/回退条件列出动作。当前 [原生预算工作簿](../backend/business_analysis/budget_excel.py)已有可编辑参数与公式，[诊断动作合同](../backend/ai_assistant/business_screening_runtime_contract.py)已有责任、前提、观察天数和回退字段，但 renderer7 将动作以规范 JSON 分片放入“调整规划与证据”，尚未提供这种可直接执行/复盘的计划表。现有 [HTML writer](../backend/business_analysis/report_files.py)有离线搜索、排序、分页与通用前十数值图；参考 HTML 的店铺 KPI、双逐日趋势和品类→SPU→SKU→词货下钻尚未组合成同一交互。

参考“核对与覆盖”A6:E76共有 70 项源累计、品类/SPU/SKU 回卷、版本水位、七类目两期日覆盖及推广直接/间接金额检查。当前封存页、来源摘要和筛查覆盖提供底层证据，但正式卷没有这张跨层级、可读且逐项可复算的核对清单。参考的 `提取证据目录` 也没有由 renderer7 以同样独立工作表列出；现有“来源与核对”保存每个所选来源的摘要与覆盖，语义相近但不是该次全部抽取记录与跨表验收。

## 优先实现的四个纵向切片

1. **店铺—商品归属与比较**：从可信店铺/网店、ERP、主数据和推广封存页构建版本化店铺总览、逐日联表、品类/SPU/SKU 跨源诊断与“映射异常”。明确当前主数据归属和原生 SPU 独立口径，未匹配金额只进待分配池。通过条件：本期/环比/可用同比的期间、分母与覆盖可追溯；店铺总额、逐日、品类、SPU、SKU 对原来源回卷，在退款/成本/歧义场景不重复分配、不把缺失补零；五 Agent 引用并经独立复核后，HTML/XLSX 同源同数。
2. **词—计划—商品关系与动作预算**：在现有“明确推广 SKU”两表之外，另建版本化关键词/搜索词/计划/单元/匹配/跟单 SKU 关系表及原词诊断，明确三类 SKU 身份不能互换；最近 7 天与30天指标进入计划级预算与结构化行动表。通过条件：每条推广源事实仅在对应视图累计一次，跨视图不相加；原词及缺词桶、无明确 SKU 桶不丢失，计划/词/SKU 与来源费用对账；建议逐项给对象、前提、负责人、预算原则、指标、观察期和停止条件，未执行的平台操作仍标建议。
3. **市场样本、B 端与月度财务的正式解释**：市场 v2 三表先补真实本人 Agent 派发/读取回执、数值引用及人审，再版本化扩至参考的多类目/品牌/30 天 cohort；自家 SPU 仅在精确且经确认的映射下标“类目覆盖”，不转移竞品成交。B 端缺源与有源分开证明；财务 v3 的完整自然月可用时独立列示。通过条件：价格上下界、未确认价和缺日分别保留；双日进出与30天 cohort 不混称；市场/广告归因/ERP/B端金额互不相加；无企业购或财务数据时显式不可算，不按天摊月利润，不重复扣推广费用；五 Agent/正式文件均使用同一已封存版本。
4. **可读交付与真实规模验收**：将上述已核验表、动作和逐项对账组织成清晰 HTML 导航与 XLSX 类型表，保留 renderer7 的多卷容量、不可变摘要与旧版文件兼容。通过条件：HTML 可按品类→SPU→SKU→词货追溯并查看实际日期/口径，XLSX 预算编辑后的公式在原生 Office 环境重算且不改变原报告事实；同一交付清单完整覆盖所有分卷。用本店实际规模及至少另一店、缺来源/歧义/退款组合核对记录数、金额和摘要，并单独完成 42.7 MB 级工作簿与浏览器/Office 开启验收。合成 19 来源两卷通过和旧 1–7 字节回归属于工程验证，不替代真实数据、真实模型判断或生产采用。

参考文件使用前等长环比；既有 renderer7 的 `comparison_periods` 可表达这一次日期，但新日历比较规则仍只是[版本候选](AI_BUSINESS_COMPARISON_RULES.md)。未来若启用新规则，必须在计划、来源、报告及文件固定规则 ID 和两期实际日期，不重释旧报告。参考的推广、商智、市场去年同期缺源时留空，只有有证据的 ERP 指标可算同比；该差别应成为正式比较可用性门禁。
