# 报告模板、Skill 与 AI 流水线

2026-09-14 第一阶段已合入 main 并在本机生产采用。源码 `13ad0770`，Worker/helper `20260914T103055Z-476613e9da6a6b1d`；采用证据见 [发布核验](evidence/ai-report-library-production-20260914.json)。

## 面向使用者的行为

AI 助理新增报告模板、Skill 管理和 AI 流水线三个入口。首版由无数据范围限制的管理员管理和启动，任务与文件仍按真实创建人及实时权限隔离。

- 报告模板固定场景、章节、取数步骤、写作要求和主交付格式。内置网店经营周报、库存健康报告、推广复盘。均可下载 HTML 与 Excel。
- Skill 保存简短描述、触发词、适用领域及 Markdown 方法正文。普通聊天根据触发词和实际工具目录最多选择三条；Agent 创建时固定方法快照。执行详情显示本次使用的技能及版本。流水线显式选择一至三条技能。
- 流水线选择模板、技能、平台、精确店铺或仓别及含首尾日的日期范围，复用现有持久 Agent/DAG 队列执行核验取数、分析报告、人工复核。空跑不调用模型。正式报告须通过复核；完成通知另选已有渠道并明确确认。

文字 Skill 只提供方法指导，权限、指标公式和工具边界仍由代码控制。导入导出仅支持本系统的 JSON frontmatter Markdown 格式，首版不兼容任意 YAML 技能包，不导入脚本、ZIP 或目录资源。流水线为手动启动的固定步骤，不提供任意拖拽图、定时报告、生图节点或自动业务写操作；既有 Agent/DAG 和 n8n 功能继续独立。

## 版本与交付

资源库采用全局递增版本和 expectedVersion 比较更新；旧版本不可修改或删除。停用代替删除，历史单项可通过编辑并保存为新版本恢复。版本记录每页二十条。新任务固定模板、技能、范围和库摘要；修改库不改变进行中任务。

报告编号与原工作流一一绑定。相同用户请求标识重复提交返回原任务；相同范围、快照、模式的在途任务复用，未知模型结果沿用原队列的隔离与安全恢复规则。任务仍依赖本机后台执行器在线，关闭网页不取消任务。

模型须输出与模板章节完全一致的结构。自由文本、缺章和无成功来源的结果保留供复核，不自动重跑。通过复核前服务端必须验证报告结构、成功的数据覆盖检查及业务取数回执；这不替代人工核对数值、范围和结论。

HTML 仅转义文本并使用固定样式；Excel 为无公式、无宏、无外链的静态交付文件，数值明细可继续计算。文件从该任务已持久化的工具回执生成，下载不重新取数或调用模型。明细保留来源参数、摘要、覆盖、分页及截断信息，不声称全量业务导出。沿用敏感字段过滤。

边界：资源库最多二十四个模板、二十四个技能和十二条流水线，合计 128 KiB；单次报告快照 32 KiB，执行指导 64 KiB；日期范围一至九十三天；工具证据最多八十条、1 MiB；导出最多一百分表、两千行、六十四列、2 MiB。超过上限明确拒绝，不静默截断。

通知仅发送报告完成摘要及编号，不附带报告正文或文件。发送前固定渠道配置摘要并持久预留；目标变化拒绝，已有预留、成功或未知结果均不重复发送。通知失败不会撤销已完成报告。

## 实现与权限

权威实现为 `backend/ai_assistant/report_library.py`、`reports.py`、`report_render.py`。公开 Worker 路由只做鉴权和签名适配。`report-library` 由管理员管理；报告及工作流读取继续执行 owner/scope 校验。文件 GET 经 AI writer 读取私有工具证据，但无数据库写入。

AI 迁移 `0012_report_library` 新增 `ai_library_revisions`、`ai_execution_guidance`、`ai_report_runs`、`ai_report_deliveries`，共五十六张 AI 自有表。前三张为不可变记录；所有表安装运行时写栅栏，投递表无 DELETE 权限。四张表均排除在通用系统数据集之外。备份、健康检查和最小权限清单同步识别 0012；0011 环境仍按五十二张表验证。

旧任务没有指导快照时保留旧行为，不回填历史记录。普通聊天保留原配置快照机制，并记录本次选用 Skill；新独立 Agent/DAG 从创建时固定业务指导及 Skill，子任务继承父快照。
