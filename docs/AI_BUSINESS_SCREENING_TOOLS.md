# 固定筛查的只读工具服务

第四十一批实现角色包、固定预算及原生/映射分析的 owning 服务；本批自身不注册模型入口。读取必须绑定真实报告、证据及首次固定的筛查 ID；只有完整发布的结果可以准备，固定意图本身不等于准备完成。

一个内部准备对象只构造一次五角色包，复用时重新检查当前账号、报告、封存、发布记录及独立保存的五个角色摘要。包页保留原有协议，不额外包一层导致超过38000 UTF-8字节；原始字节、内层摘要或角色顺序变化都拒绝。公开 JSON 不能恢复准备对象。单次 HTTP 请求仍独立准备，不引入跨请求授权缓存。

预算必须显式完整解析；没有预算或尚未解析不能返回空成功。预算页的包裹协议与容量预检一致。原生分析及显式关联分析分别从完整封存流重新计算，缺映射计划时拒绝关联请求；上下文退出后仍核验权限。预算及分析页仅按完整行前缀缩页，保留全部列和实际 nextOffset，单行超量则失败。

独立复审发现同报告的内层角色包可被整组自签替换，已通过外层独立固定五个摘要修复；没有通过每页重新构建五包来掩盖问题。验证包含实际来源流耗尽、末尾异常、原生/映射/预算的迟到撤权、四种可选参数组合及相同报告的替换负测。测试与后续路由接入分别记录，见 [服务候选证据](evidence/ai-business-screening-tools-candidate.json)。

工具正确返回不代表任何 Agent 已读。实际调度需要先完成容量准入；模型调用还须按自己的任务逐页读取，并通过 [独立读取证明](AI_BUSINESS_SCREENING_RECEIPTS.md)，之后才能进入诊断、人审和文件交付。
