# 筛查报告的完整多卷 HTML/XLSX

第五十一批沿用 renderer 4 的持久多卷交付，将新筛查报告接入完整原始规范明细、原生分析、同比环比、显式商品关联和固定预算。新增筛查来源、请求覆盖、表核对、规则分区、全部保留候选、五角色阅读范围和实际读取回执附表；候选附表不替代完整明细。

嵌套证明记录保留完整规范 JSON，以记录序号及片段序号拆为四列，单片最多 7000 个 Unicode 字符，不截断长文本或动态指标。用户可按目录重组；分区同时披露匹配、保留、省略数量，不把重复命中的金额相加为损失。HTML 与 XLSX 同源生成。

完整清单新增成组的固定筛查引用、包协议及五角色包摘要；缺项、错配或篡改拒绝。旧格式的 HTML、XLSX、精简清单及完整清单字节保持原规范。总计仍最多 100 卷、1 GiB，单表/文件/列数边界不变；超限不裁掉表。

新模式创建、恢复和最终发布前，在最外层事务之外验证全部内容、预算和读取证明。提交时复核私有准备对象、实际账本 SHA、身份和版本。分块下载只核对固定根、权限和分块摘要；已完成暂存可复用，不重复渲染。迟到账本变更使文件停留待处理状态，不能冒充 ready。

真实 HTTP 创建与恢复的业务变更和完成回执同事务；提交失败保留 processing 防止不确定重放。合成与旧格式兼容验证见 [候选证据](evidence/ai-business-screening-files-candidate.json)，不代替实际 Excel 打开复算及真实报告质量验收。
