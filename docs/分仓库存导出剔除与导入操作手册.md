# 吉客云「分仓库存」导出、精确剔除与导入操作手册

适用范围：吉客云可按日期查询的历史分仓库存全仓导出，精确剔除仓库名称为“刷刷仓”的数据后，导入运营管理系统分仓库存快照。每日自动化必须以[吉客云自动化状态机与下载后处理](./吉客云自动化状态机与下载后处理.md)为动作规范。当前入口若只能提供实时库存或没有历史日期控件，不得执行正式导入。

## 1. 固定边界

- 分仓库存是每日五类任务的第 2 项；只有同一 `RUN_ID` 的 `products` 已完成才可开始。
- 继续使用同一个吉客云任务标签页，不新建独立标签页。
- 快照日期固定为北京时间执行日的昨天，并必须由页面历史日期控件的精确读回证明；调用参数或处理文件生成的元数据不能替代源证据。
- 原始文件必须是本模块下载事件返回的 `D:\谷歌浏览器\分仓库存查询*.xlsx`，不得复用或改写。
- 只剔除 `trim(仓库) == "刷刷仓"`；相似名称必须保留。

## 2. 状态驱动导出

1. 进入可按业务日期查询的历史分仓库存来源，逐字段读取当前值；若入口是实时库存或找不到历史日期控件，以 `FIELD_MISMATCH` 停止。
2. 仓库字段未全选时，只操作仓库字段：点击全选、确认，再读回“已勾选数量”和全选状态。历史仓库数量只作量级参考。
3. 读取并核对页面日期为昨天；若需修改，只改日期字段并立即读回。
4. 查询前记录表格指纹并持久化 `queryIntentAt`，筛选按钮只点击一次。
5. 观察属于本轮查询的加载开始与恢复或指纹变化；页脚总行数/指纹间隔 500～1000 毫秒连续两次一致后，保存 `expectedSourceRows`。页面条件仍须与读回值一致。
6. 在同一受支持的浏览器调用中建立下载监听、持久化 `exportIntentAt`、只点击一次“导出所有页（限 500000 行）”。
7. 仅接收下载事件返回的绝对路径，并确认最终 `.xlsx`、无 `.crdownload`、文件间隔至少 1 秒稳定。不同 SHA 的多个候选立即 `BLOCKED`。

页面级等待上限为 60 秒；期间只轮询读取，不重复筛选或导出。

## 3. 统一 runner

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "D:\运营管理系统\tools\jackyun-download-runner.ps1" --module inventory --file "<下载事件绝对路径>" --handoff-file "<本轮 02-inventory.json>" --run-id <RUN_ID> --export-start <exportIntentAt> --expected-source-rows <expectedSourceRows> --snapshot <昨天YYYY-MM-DD>
```

runner 自动完成：

- handoff schema 为 2，`RUN_ID`、策略版本、模块与 provenance 一致；历史日期读回、查询、刷新完成、表格稳定、导出与下载事件的时间顺序一致，且目标日与读回日精确相等；
- 文件目录、名称、时间窗口、下载 ID、稳定状态、字节数和 SHA-256 绑定；
- 工作表及 `货品编号`、`货品名称`、`规格`、`单位`、`仓库`、`库存数量` 必需列校验；
- 原始真实行数与页面 `expectedSourceRows` 精确一致，且正常情况下不少于 20,000 行；
- 只精确剔除“刷刷仓”以及缺失、负数或无法解析的无效固定成本；明确填写 `固定成本价 = 0` 的明细必须保留，并记录原始、刷刷仓剔除、无效成本剔除、零成本保留和最终保留数量；
- 生成带快照元数据且已剔除刷刷仓及无效成本的确定性库存导入文件，不修改原始下载；
- 同时保存本轮原始库存副本作为销售成本源，销售侧读取该副本时排除刷刷仓；库存零成本保留口径不改变销售成本匹配与毛利清洗规则；
- 使用 localhost 分片接口导入，并直接核对本轮精确批次的 `completed`、快照日期和行数。

无需人工打开 Excel、复制到临时目录、启用 Chrome 文件 URL 权限或通过页面上传。

## 4. 成功与阻塞

成功审计位于 `outputs\jackyun-import-runs\<RUN_ID>\audit\inventory.json`。只有 runner 返回 `completed` 才可进入库龄。

若仓库全选无法读回、页面刷新无法归属于本轮、文件行数不一致、过滤或导入失败，停止后续模块；保留原始文件及失败审计，不重复点击。

```text
模块：inventory
原始文件：<绝对路径；字节；SHA-256>
页面/文件数据行：<expectedSourceRows>/<sourceRowCount>
预处理：刷刷仓 <excluded>；保留 <retained>；相似名称 <列表>
快照日期：<YYYY-MM-DD>
导入批次：<batch id>
结果：新增 <n>；更新 <n>；警告 <n>
```
