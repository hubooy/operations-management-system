# 市场 v2 报告停放画像（0044）

0044 只允许内部创建**停放**的市场 v2 报告根和工作流，工作流固定 `status=paused`、`error_code=market_material_not_admitted`，没有节点任务、Agent、模型派发、正式市场工具、文件或公开入口。现有通用调度器只领取 queued/running；数据库门禁拒绝本画像直接 queued/running、之后任何工作流状态更新以及与该工作流关联的 Agent job。报告创建使用当前无范围管理员、同一已封存词货 v1 来源报告和 v2 证据，并在写入前运行拥有方市场三表完整候选准备。

持久 snapshot/workflow 只保留数据库可独立复验的根：源报告/工作流原文字节摘要、封存证据 ID/版本/摘要、京东市场本期/基期的真实来源键、同榜单查询、价格带、两日观察规则、固定算法版本，以及确定的五角色图摘要、拟议工具顺序与角色策略摘要。**实际** `allowed_tools_json=[]`、工具策略为该空清单的摘要；`proposedTools` 只是未注册的不可执行计划，不冒充当前工具目录可用。0044 SQL 从旧报告、封存来源行和完成检查点重建这些身份；它拒绝缺覆盖日期、跨榜单/基期、重叠或无效价格带、伪造源摘要、图/工具字节、账号和预算标记。报告快照与工作流输入字段集合严格受限，`marketMaterialReady=false`、`registered=false`、`humanReviewRequired=true`。原词货 v1 和旧报告/renderer 1–7 的字节、创建路径和权限保持原样。

**三表派生结果不是数据库创建权威。**完整价格带和进出榜的 manifest/NDJSON SHA、行数等需要逐页拥有方重放，0044 不把调用方带来的这些派生值写进持久 snapshot；数据库也不声称已复算它们。后续须单独版本化材料准入、真实角色工具授权、Agent本人实际读取回执、引用复算和人工复核，再由新版本报告/迁移承接派发；0044 停放工作流本身不可原地转成 queued。当前任何状态转移都由数据库拒绝，不能靠改字段或运行调度器提前开始。无 renderer 8 文件生成或生产部署。

隔离 PostgreSQL 已通过 7 项创建/伪造来源空值/直接排队与 Agent job/有报告逆迁移拒绝测试；0043→0044 独立演练通过旧 77 张 AI 表摘要、renderer 1–7 文件字节、角色权限、前后备份恢复和空表逆迁移。备份静态 20 项、维护 Node 14 项通过。0044 尚未提供公共创建路由或运维激活入口，未采用生产。
