2026-09-14 用户确认：仅状态、风险、分类卡片支持“点击选中、再次点击取消”；销售额、利润率等纯汇总指标保留展示。

## 排查与调整范围

| 页面 | 分类卡片行为 |
| --- | --- |
| 运营事务 / 工作计划 | 顶部进行中、逾期、今日到期、已完成支持筛选和取消；合计显示全部状态。下方工作事项、未开始、进行中、已完成与顶部共用状态。首次展示全部状态。 |
| 运营事务 / 巡店检查、评价维护 | 处理中、已闭环、紧急事项接入服务端状态组或 priority 筛选；全部记录清除卡片条件。搜索条件保留。数量标注当前已加载口径。 |
| 运营事务 / 新品上架 | 前一轮已完成：同一卡片再次点击取消；维持分页前筛选与独立快捷计数。 |
| 运营事务 / 上新跟进 | 监控产品线、需要跟进支持切换和取消；后者匹配 no_sales / stalled。产品线清单、周报预览和 Excel 使用同一筛选集合，不修改正式投递任务。 |
| 库存 / 库存总览 | 六类健康卡片支持再次取消；已有多选条件切换为所点分类，再次点击清除此分类条件。 |
| 库存 / 备货计划 | 草稿、已确认、已完成卡片与计划状态筛选联动；再次点击清空计划状态。 |
| 库存 / 库龄、滞销清理 | 滞销、优先清理、高库龄、零销量数量卡片支持服务端精确条件；分页前筛选，清空当前页筛选也会清除卡片。 |
| 库存 / 京东入仓 | 滞销/长库龄卡片按既有 risk=stale 口径筛选，再次点击取消。 |
| 库存 / 广东入仓 | 原有风险卡片已支持切换和取消，保留。 |
| 商品经营 | 原有毛利分类多选和取消保留，点击区域扩大到整张卡片，补充 aria-pressed 和键盘反馈。 |

BI、销售/财务、网店、市场分析中的金额、比例、均价、覆盖总量等汇总卡片保留展示；市场系统配置的全库维护计数不是当前业务明细分类入口，不建立含义不明的筛选。未改变自动化执行或配置动作。

## 查询和边界

- 工作计划卡片、列表和导出共用状态及日期逻辑。今日到期按上海当天闭开区间，逾期只包括未完成且截止日期早于当天；自定义日期取交集，空交集显示空列表。日期卡片不缩小合计卡片的统计口径。
- 运营记录新增只读 priority 查询参数，严格枚举验证，保留数据范围与分页。没有当前页过滤冒充全量筛选。
- 库龄 cardFilter 仅允许 stagnant / aged90 / zero_sales；京东入仓仅允许 stale。Worker 和 Django 同时校验，拒绝重复或未知参数。零销量必须有可用库存且销量非空，高库龄为至少90天。
- 库存卡片条件尚未进入 AI consumer 契约，选中特殊卡片时页面上下文明确提示暂不支持，避免 AI 静默按更大范围回答。普通分类状态、原有查询和权限保留。
- 本轮没有新增迁移或业务写入。沿用原任务独立 worktree 和只读合成预览；此前店铺规划迁移仍须随该任务另行验收采用。
