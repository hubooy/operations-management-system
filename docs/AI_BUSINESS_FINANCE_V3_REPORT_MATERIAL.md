# v3 同封存报告意图的财务月度材料候选

内部 `business_finance_v3_report_material.prepare(intentId, sourceKey, principal)` 只接受当前无范围管理员、同一已封存 v3 证据和其暂停的报告意图。它复用有用途隔离 HMAC 句柄的 v3 拥有方读取桥：首次读取先完整复核所有来源与成功工具收据，然后选定一个 `finance/monthly_context` 来源；将该来源的所有有限行切片按原序号重组成完整页，逐页复核原始摘要、来源修订、完成批次和控制计数。最后再次复核暂停意图、账号、封存目录与收据链。失败时不返回部分月份或表格。

材料保留该财报来源的原始行、每月真实发布/缺月状态、summary 与金蝶、合计与明细、合并行等控制计数及源金额分/比率基点。环比仅比较相邻自然月，同比仅比较上一年同月；基期未在本次连续月份内、缺月、缺科目、空值、非数值或同指标多科目都保持非数值状态。金额在两个月都为明确数值时给差额和安全比率；零/负基期不伪造百分比。源比率只给基点差，不累计月比率或把变化说成利润增幅。自然月财报不按日摊到近30天、SKU、SPU、关键词，也不与可能重叠的 ERP/B端/推广金额直接相加。`upstreamSourceSignatureVerified=false`、`agentReadReceiptRecorded=false`、`reportGenerationSupported=false`。

现有 v3 读取桥在**整任务**超过64个事实页或8MiB时返回413，材料服务沿用此硬边界；它不会截断为“已完成”。财报源本身和返回材料亦受8MiB上限。参考更大规模报告仍需后续版本化读取证明与资源验收。这里仅准备一个来源的月度背景材料，不注册Agent、模型、公开路由或工程报告文件；正式运行和文件产出仍受五Agent、人工复核及独立准入约束。
