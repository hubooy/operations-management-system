# v4 封存单次票据：0041 安全闭合候选

0041 只安装数据库票据发行和一次领取。专用 `teruisi_ai_seal_writer` 仍为 **NOLOGIN**，没有密码、CLI、公开入口或调度。迁移同时撤销该角色对 0040 三只无票据读取函数、0038 直接封存函数和 0037 直接锁源探针的执行权；因此本阶段**不能读取 v4 原始页，也不能封存父任务**。不应把拿到票据或领取回执当作封存成功。

AI writer 将来只能在已认证当前管理员请求处理器中发行。数据库再次核写入权威、当前无范围管理员及版本、`collecting/manual` 父任务、最新且晚于来源写入门禁的验证尝试、完整的 2–4 个来源，并按固定 UTC 口径计算所有来源行的根摘要。数据库不能仅凭共用的 `ai_writer` 会话独立证明 HTTP Principal；应用签名负责请求真实性，数据库票据负责专用角色的行隔离，两者不可互相代替。

发行函数用 PostgreSQL 内建的两次随机 UUID 生成 64 位十六进制 nonce，库内只存带用途前缀的 SHA-256。nonce 只返回一次，票据必须在数据库时间的 60 秒内领取。发行请求摘要唯一；重复请求不会返回旧 nonce。领取函数仅接受准确 nonce、父任务/尝试/账号版本与未变化的来源根，写入唯一、不可变的领取记录并返回另一枚只出现一次的 claim token；领取租期为 180 秒。票据和领取表对普通 AI reader/writer 以及专用角色都没有直接 SELECT 或 DML 权限，行级不可变与禁止 TRUNCATE 触发器另挡误授权限；数据库所有者仅为隔离测试清空及受控维护可执行 TRUNCATE。

**尚缺的 0042：**每页/段读取均须在数据库校验票据与领取 token，并在有效租期内绑定精确 run、attempt、source、sequence；最终短事务应重核当前账号、目录和来源修订，调用 0038 原子封存并在同一事务写消费回执。0041 没有消费状态或结果未知查询，不能声称具备可续跑封存。180 秒租期尚未在参考约 57.5 万行来源上验收，超时或进程崩溃目前只能等待租期结束，由当前管理员以新请求重新发行；不得默许延长或重用旧 claim。密钥、nonce、claim token 不得写入参数、输出日志或备份证明。

迁移逆向只在两表均为空且专用角色仍为 NOLOGIN 时恢复 0040/0038 的历史执行 ACL；任何已发行或已领取票据都拒绝逆迁移。历史 74 张 AI 表清单保持冻结，当前清单新增票据和领取两表共 76 张；单 MVCC 备份按迁移存在性核对。生产激活、密钥文件、签名请求与恢复库旧票据失效仍另需受控设计与验收。
