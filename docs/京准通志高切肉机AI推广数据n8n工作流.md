3. C 节点逐个重新读取保存文件并重算证据，按精确 batch ID 回查 `completed`、零告警、店铺、日期、行数和原文件哈希，最后再次确认计划日均已覆盖。无缺口时不启动 Chromium、不生成或下载任务。
