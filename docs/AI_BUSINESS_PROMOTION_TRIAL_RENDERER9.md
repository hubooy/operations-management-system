# 推广专项试用文件候选（renderer 9）

2026-09-24。本切片只在独立开发分支提供 `business_promotion_trial_volumes.open_volumes` 临时 HTML/XLSX 与完整 JSON 清单；未注册文件生产者，不创建文件任务，不开放页面或下载，不进入正式数据库，不调用模型或执行广告调整。原 renderer 1—7 的入口和文件内容不改。

输入沿用同报告、当前账号、五 Agent 完成并实际人审批准的现有链路。文件仍保留原批准内容规范 JSON、逐条结论 JSON、封存原始/原生来源表和两张完整词货视图；两张词货表保持最后位置，费用不可相加。v9 新增：

1. `promotion-approved-actions-v1`：每条批准的行动一行，显示对象身份、调整建议、前提、成功指标、观察天数、回退、优先级、责任角色、原始引用与数值。身份缺失或冲突的行动仍保留，并明确不可执行。预算影响为批准原文和“待核”，不是重新分配结果。
2. `promotion-trial-source-scope`：每个封存来源的实际比较窗口、原始日期、身份、行数/页数、修订水位、缺日、缺值行及摘要。此处“已核对”仅指系统来源控制汇总与明细守恒，不证明平台最终结算。
3. `promotion-trial-boundaries`：店铺区间 UV、B 端包含关系、市场、月财务、预算和 SKU 身份的未交付或待核说明。

完整清单的 `promotionTrialProof` v2 绑定报告、批准内容和人审摘要、原 renderer7 词货材料证明、封存来源摘要、全表描述摘要、版本化表声明摘要、行动行数与行摘要及两张词货表身份。表声明摘要覆盖标题、说明和列 key/标签/类型/合计/比率引用，发布前按当前声明重算。HTML 与 XLSX 各卷来自同一遍行流，完整清单逐片记行摘要、工作表名称、文件大小和 SHA-256；receipt 含所有卷的可核文件清单。试用版预算硬性为 `nativeBudgetSheets=0`、`offlineBudgetEnabled=false`，没有可编辑预算公式或离线情景。即使批准内容 JSON 含预算相关文字，也不能称预算功能已交付。

现有容量边界不放宽：单卷最多 120 表、单片最多 100 万行、单文件最多 256 MiB、交付总量最多 1 GiB；实际字节超限失败关闭，不截断。候选文件仅在 context 内存在，退出前再次核临时文件 SHA 与批准版本。独立 PG 目标测试与旧 renderer7 文件回归必须在集成前完成；合成验证不替代真实业务、原生 Office、浏览器规模或生产采用。
