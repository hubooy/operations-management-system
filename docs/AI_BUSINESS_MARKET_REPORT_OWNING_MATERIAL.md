# 同一封存 v2 报告的市场材料

内部 `business_market_report_material.prepare()` 将现有市场准入、京东市场拥有方完整页重放和三张类型表核验收敛为一次临时材料准备。输入必须是同一已封存词货 v2 报告、当前无范围管理员、明确的本期/基期来源键、价格带和两日观察日期。准入先核报告快照、封存版本与 Reader.info 覆盖；完整材料再从该报告的固定页链计算价格带汇总、价格带成员和固定两日进出榜，并核每页字节摘要、游标/来源身份、完成检查点、清单与逐行 NDJSON 类型表。任何一步失败都不返回部分材料，离开 `prepare()` 生命周期后表不能继续读取。v2 协议没有 v3/v4 的逐页独立签名工具收据，本模块不声称上游数字签名权威。

本期与基期必须具有相同京东市场榜单范围及明确不同窗口，观察日必须在各自封存来源覆盖内。缺日期是 `date_not_covered`，不等于零销量或未进 TOP。价格带汇总和成员是同一市场样本，不能相加；市场样本 SKU/SPU、区间成交金额不证明本店、ERP 或 B 端销售归属。结果明确保持 `authorityVerified=false`，未注册 Agent 工具、模型调用、公开路由或 renderer 8，也未写任何报告文件。

后续 Agent/文件阶段须在正式 dispatch 和人工复核边界内消费该临时材料，并在文件可见前完成最终账号、报告和封存来源复验。当前 v2 单来源最多2,000页/约64MiB，完整三表也有行、字节和临时空间上限；参考57.5万行京准通大来源与 v4 的扩容问题不由本模块解决。
