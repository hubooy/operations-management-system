# 每个 Agent 的独立筛查读取证明

第四十二批增加读取证明重建服务，尚未接入运行时的派发或完成门禁。它从实际 Agent、所属工作流节点、固定报告和不可变工具账本核验，不接受模型自报已读，也不能借用其他 Agent 的回执。

任务、节点指令、依赖集合、输入、模型版本及工具目录均须与本次固定图一致；工具目录必须是三个不同字符串组成的列表。每次最多读取40条派发，单工具最多8次，失败派发也计数。调用序号连续，工具和 provider dispatch 均属于本人任务，成功回执必须有同名审计标记和正确摘要。

每个角色必须从0开始沿真实 nextOffset 读完自己的全部包页；缺页、重复、乱序、其他角色、其他筛查结果及自签篡改都拒绝。读完角色包后才可核预算及额外明细。推广、独立复核、整合角色必须读完固定预算；其他角色一旦开始读预算，也必须读完。额外原生或映射分析的每个成功页由 owning 服务重新计算核对，不机械要求重复阅读已有候选对应的映射第一页。

证明保留实际 job/role、包摘要、页数、预算完整性、额外明细页数及原筛查覆盖语义。完整规则扫描、所有保留候选已读、来源日期完整和实体逐日完整是不同结论；这里不能声称因果已验证或所有原始明细已被模型阅读。

12项纯账本测试使用真实角色包编解码，明确模拟 owning loader 与账本查询；另有真实 PostgreSQL 固定结果及不可变合成账本组合，验证五任务各自读取、必读预算和篡改后的已知回执保持。未知结果立即拒绝且不调用工具或模型，重复核验失败也不重放。详见 [候选证据](evidence/ai-business-screening-receipts-candidate.json)。

这些通过项不等于真实模型、运行调度、人审和 HTML/XLSX 已完成接线。
